NILE CALLIGRAPHY WEBSITE — COMPLETE LOCAL PREVIEW

This folder contains the complete website, not just the homepage patch.

HOW TO VIEW
1. Extract the entire ZIP folder first.
2. Open the extracted folder named "Nile Calligraphy website".
3. Double-click index.html to open the homepage in your browser.
4. Use the navigation to open the other pages in the pages folder.

IMPORTANT
- Keep the css, images, js, and pages folders beside index.html. Do not move files out of their folders.
- The homepage uses the existing Special1 and Special2 artwork images in the Signature Collection.
- The exhibition extra photos remain in the images folder for later use.
- All existing pages share a consistent navigation menu linking only to real pages in this project.
- Responsive layout overrides are loaded last so mobile/tablet rules take priority across the homepage, catalogue, and exhibitions pages.
- Updated project 2 and project 8 image references use product2.jpeg and product8.jpeg consistently.
- This is a static HTML/CSS/JavaScript site. Some online services (such as Google Fonts) need an internet connection.
- Search/cart/backend purchasing features are not connected to a server and should not be treated as a live ecommerce system yet.

CATALOGUE UPDATE
- Original Paintings now contains a searchable/filterable preview collection and a matching detailed section for each currently included artwork.
- Homepage artwork links jump directly to the matching artwork section using URL anchors.
- Saved-artwork shortlist is stored locally in the visitor browser; it does not require an account or backend.
- Confirm artwork titles, whether visually repeated files are separate originals, and actual price/medium/dimensions/availability with the artist before publishing those details.
